## التنظيم والهدف
الأعمار 11–16؛ ثلاثة طلاب وكرة لينة وممر 3×9 م. ثلاث علامات بخطوات مريحة؛ الممرر جانبًا والمستلم النهائي بعد الأخيرة بـ3 م. الهدف تسلسل متحكم للاستلام والخطوات والتمرير.
## الخطوات والوقت
7 دقائق: 2 عرض، 4 تدريب، 1 ملاحظات. استلام ثابت قبل العلامات ثم ثلاث خطوات مشيًا مع الكرة وتوقف. تمرير للمستعد وإعادة الكرة قبل تدوير الأدوار. نحو ثلاثة أدوار لكل طالب حسب الوقت. تسلسل تعليمي لا اختبار كامل للقوانين.
## الإرشاد والسلامة
تمرير لطيف ومشي فقط. يعدل المعلم العلامات بدل فرض طول خطوة. لا تمرير لغير المستعد أو عبور مسار نشط. فشل الالتقاط: توقف وإعادة.
## التكييف والتقويم
تسهيل: التقاط وخطوة واحدة. تصعيب: تمرير بعد الثالثة دون توقف طويل أو وثب. لمسار وسائل التنقل ثلاث نقاط توقف بهدف مختلف. يلاحظ الترتيب والتحكم والنظر قبل التمرير.
صياغة مستقلة دون نسخ نصوص أو وسائط خارجية. الأعمار والأوقات والمعايير مقترحات. مسودة لمراجعة المعلم والتحرير اللغوي والتجربة الميدانية؛ ليست تصريحًا قانونيًا أو ضمانًا لغياب حقوق الغير.
