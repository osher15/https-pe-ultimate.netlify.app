Protocol and equation
Léger LA, Mercier D, Gadoury C, Lambert J. The multistage 20 metre shuttle run test for aerobic fitness. J Sports Sci. 1988;6(2):93–101.

Default protocol: 20 m shuttles, level 1 at 8.5 km/h, +0.5 km/h per level, each level about one minute.

VO₂max is an estimate from the Léger et al. (1988) equation: 31.025 + 3.238·S − 3.248·A + 0.1536·A·S, where S is the speed (km/h) of the level in which the last full shuttle was completed and A is age in years. It is shown for the 20 m course only. It is not a medical test or a diagnosis.

No norm or threshold table is included. Any thresholds you enter are your own.

Privacy: the tool works offline, has no account and sends nothing over the network. Settings, the runner list and results are stored only in this browser on this device (storage key prefix "pe-shuttle.v1"). Export a CSV to keep a copy. "Delete all data on this device" removes everything.

Safety: this is a maximal running test. Check that runners are fit to take part, warm up first, and stop anyone who feels unwell. Audio timing depends on the device; check volume and beeps before testing a group.
