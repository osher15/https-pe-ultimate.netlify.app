# Support knowledge base — English draft

Support contact: {{SUPPORT_EMAIL}}. Do not include pupil names, photos or personal records in support requests.

## Open a standalone download
Locate the downloaded package and read its included README. Open the supplied HTML file in a supported browser, if that is the delivered format. Availability and physical-device support must be confirmed for each product.

## A file does not open
Check that the download is complete and, for a folder-based package, that accompanying files have not been separated. Record the file name, product version and error message, then contact support.

## Using resources offline
Some standalone HTML boards have been checked while opened as local files without a network connection in desktop or emulated Chromium. This does not verify every phone, tablet or browser.

## Language selection
Use the product's language selector when present. Store translations may have been drafted with AI; report wording problems to support.

## Saving and backing up work
Standalone board data may stay in the current browser's local storage. Clearing browser data or switching devices can remove access to that work. Export a copy where the product provides an export feature. Do not promise cloud synchronization.

## Scoreboard data after reload
The scoreboard has a known autosave-after-reload defect in the reviewed build. Do not promise automatic persistence until the fix is implemented and retested.

## Sharing and licences
Read {{TERMS_URL}} for the approved licence. The draft Single-Teacher licence covers one named teacher; the draft School licence covers eligible staff at one campus.

## Refund or duplicate order
Send order details to {{SUPPORT_EMAIL}}. Refer to {{REFUND_POLICY_URL}} for the reviewed refund terms and applicable rights. Do not request payment-card details by email.

## Accessibility feedback
Describe the affected screen, keyboard or assistive technology issue and browser where known. Accessibility of the standalone products has not been fully verified.

## Content corrections
Provide the product name, lesson or activity ID, language, and suggested correction. A teacher decides how to adapt activities to their group.
