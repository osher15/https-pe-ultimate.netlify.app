# Support reply macros — draft

Draft only; review before sending.

## 1. Open on a phone

Please read the included README and check the format of your download. Physical phone support is not yet confirmed for every product.

## 2. Open on a PC

Open the included README, then open the main file in a suitable desktop browser. Keep accompanying folders together.

## 3. Open on an iPad

Read the included README. We have not completed physical iPad acceptance testing for every product.

## 4. File will not open

Please send the file name, product version and error message to {{SUPPORT_EMAIL}}. Avoid sending pupil data.

## 5. Change language

Use the language selector if the product includes one. Please report wording errors.

## 6. Lost data after clearing browser

Browser data may have been stored locally and can be lost when browser storage is cleared. We cannot promise recovery without an exported backup.

## 7. Create a backup

Use the export or backup option if available, then save the file somewhere you control.

## 8. Delete local data

If you wish to remove locally stored work, check the product's data controls and browser storage. Export anything you need first.

## 9. Share with a colleague

Please review your licence at {{TERMS_URL}}. A Single-Teacher licence does not cover colleagues generally.

## 10. Bought the wrong licence

Send your order ID and desired licence to {{SUPPORT_EMAIL}}; we will review options under the licence terms.

## 11. Duplicate purchase

Send both order IDs to {{SUPPORT_EMAIL}} so we can review the duplicate purchase.

## 12. Refund request

Send your order ID and request to {{SUPPORT_EMAIL}}. Policy: {{REFUND_POLICY_URL}}. Statutory rights remain.

## 13. Accessibility issue

Tell us the affected screen, browser and assistive technology. Accessibility verification is ongoing.

## 14. Report a content error

Send the product, lesson ID, language and proposed correction. Do not include pupil-identifying data.

## 15. Scoreboard did not save

The reviewed scoreboard build has a known autosave-after-reload issue. Export a copy where possible; contact support if data was affected.
