# PE Ultimate — תסריטי פרסומת (30 שניות)

שלוש גרסאות, כל אחת בחמש שפות: **מורים לחינוך גופני**, **מנהלים ורכזים**, ו**מאמנים** (כושר, כדורסל, וכל ענף שבו עוקבים אחרי התפתחות של שחקן).

**מבנה אחיד לכל גרסה (9:16):**

| זמן | מה רואים | מקור |
|---|---|---|
| 0–3 | פתיח: הבעיה | Gemini, קטע (א), (ג) או (ה) לפי הגרסה |
| 3–22 | ארבע סצנות מהאפליקציה האמיתית, כ־4.5 שניות כל אחת | `tools/marketing-capture.js` |
| 22–27 | רגע של רגיעה: מורה או מאמן מרוצה | Gemini, קטע (ב) או (ד) |
| 27–30 | כרטיס סיום: לוגו, «pe-ultimate.netlify.app», «5 שפות · עובד גם בלי רשת» | GPT (Key Visual) + טקסט |

**הסצנות מהאפליקציה** (קבצים בשם `<lang>_<scene>.mp4`):
`join` (חיבור כיתות) · `test` (הזנת מבחן) · `beep` (ביפ טסט) · `att` (נוכחות) · `grades` (ציונים) · `idx` (מדד הכושר) · `player` (כרטיס שחקן) · `prog` (התקדמות הקבוצה) · `hub` (מרכז הכיתה)

| גרסה | סצנות, לפי הסדר | פתיח / רגיעה |
|---|---|---|
| מורים | test → beep → join → att | (א) / (ב) |
| מנהלים | hub → grades → idx → prog | (ג) / (ב) |
| מאמנים | test → player → beep → prog | (ה) / (ד) |

**כללים לטקסט ולקריינות**
- כ־55–65 מילים לקריינות של 30 שניות, ושורה קצרה אחת על המסך בכל סצנה.
- הטענות כאן נכונות לאפליקציה כפי שהיא היום: 5 שפות, עבודה בלי רשת, נתונים שנשמרים במכשיר, ביפ טסט, מבחני כושר, נוכחות, ציונים וחיבור כיתות.
- אין כאן מחיר ואין הבטחות מספריות («חוסך X שעות»), כי אין לנו נתון שמאשר אותן.
- את התרגומים כתבתי בעצמי. לפני פרסום רחב כדאי שדובר ערבית ודובר רוסית יקראו אותם.
