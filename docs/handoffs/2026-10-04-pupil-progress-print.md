## Delivered gap
Existing class/pupil Excel and CSV exports are teacher data reports. Add a pupil-facing readable document via a teacher-reviewed preview, without duplicating the assessment engine or introducing pupil accounts.
Class report requires explicit stable pupil selection; pupil context offers only that pupil. Preview and optional history use the same validated period snapshot. Output includes name/ID, real-class label, period/inclusive dates, required test names/units, best/date and measured/missing/exempt statuses. Zero is measured; missing/exempt values remain blank. History defaults off, remains period/pupil scoped and marks invalid values without inventing zero.
An allowlisted document model strips all other pupils, grades, teacher notes, exemption reasons and measurement internals. No entire snapshot/store is embedded. A fresh stored-context check and globally unique stable ID are required before rendering, printing or downloading; stale state clears/disables the preview. No storage writes. Printing is requested only by the teacher's button, through the preview frame; PDF save is the browser's print flow. An offline HTML download is an alternative local document. No external sending, public link, login, authentication or access-control claim.
HTML escapes all text and contains no scripts, storage reads, links or external assets. Restrictive CSP blocks script/network execution; preview sandbox allows same-origin access for the parent print action and modals but no scripts. Browser/native print availability requires separate physical acceptance.
