## Behavior and boundaries
The prior grid supports manual new-attempt entry but cannot fill a whole table from Excel. Optional Work with Excel controls add an actual offline .xlsx template and tab-separated cell paste into the existing grid draft. No clipboard permission, network call or dependency added.
Measurements sheet: sid, reference name, exact required-test IDs, blank new-result cells. Stable IDs are literal text, including leading zeroes. Context carries real class/period/inclusive dates. Tests explains names/units; Exemptions lists the selected pupils' whole-period exemptions with reasons. Pupil-only scope exports only that pupil. Names are informational and never identity keys.
Copy Measurements cells including headers from Excel, paste and review. Header columns may reorder but must match exactly; pupil rows may reorder. Standard spreadsheet quoted cells, CRLF/BOM and decimal comma supported. Reject unknown/duplicate IDs, ragged/invalid quoting, duplicate/missing/unexpected headers, formulae, grouping/scientific syntax, excess precision and period-exempt results. Reuse the pure grid append validation for date, zero-time, fractional counts, stable IDs and complete atomic validation. Bound text to 1 MiB, columns to 100, rows to 10,000 and new measurement cells to 2,000. Preview shows first 100 values with explicit total/all-values notice when larger.
Review shows pupil ID, test/unit, current draft value, pasted value and chosen class/period/date. Apply only changes draft fields; blanks never erase current draft. Conflicting nonblank draft values require explicit confirmation. Revalidate preview text/date/draft and fresh stored context after confirmation. Saved history and grades remain untouched until explicit Save appends the approved draft through the existing storage guard. Save blocks unapplied nonblank paste; closing paste-only work asks first. Download failure and quota failure preserve draft.
No arbitrary Excel/CSV file reader, automatic assessment-to-grade aggregation, replacement of old attempts, new store/schema, restore transport, native or builder edits. Content-bank import hold remains separate and unchanged.
