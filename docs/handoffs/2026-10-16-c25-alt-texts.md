## Delivered

## Method
- Did not reuse the ChatGPT draft (`origin/codex/g1-notion-export-pilot-20261014`), which is formulaic and leaves names untranslated.
- Movement, start position, direction and props come from the animation specs' form checklists (README block generated from `src/specs/*.cjs`) and `library.json` equipment (bar, bench or box, dumbbells, band, wall, mat, stopwatch for holds, imaginary rope, camera view such as front for skater jumps).
- Exercise names in he/ar/ru/es are the trainer's localized names (`window.PE_IT_DATA.exercises[].name`), with parentheticals dropped.
- Dead bug, Bird dog and Hollow hold are Latin in the trainer's he/ar/ru data, so the alt texts transliterate them into the local script. This is the only deviation and is declared in `NAME_EXCEPTIONS` in the test (the test also fails if the trainer ever localizes them).
- Texts describe only what the figure does; no training advice, claims or brand words.
- English uses singular/lowercase forms in a sentence. In ru the name is a nominative caption prefix.

## Checks
- 47 ids equal `library.json`; exactly the 5 languages per id; non-empty, trimmed, <= 120 characters (code points).
- No identical text across two exercises within a language.
- he/ar/ru contain no Latin letters (empty allow-list), contain the right script and none of the others.
- he/ar/ru/es each contain the trainer's localized exercise name (en is not name-checked because of plural forms).
- No FITNESSGRAM / PACER / Cooper words (Latin and transliterated).

## Limitations
- AI-written. Not checked by native speakers; he/ar/ru/es wording, grammar and gender/case choices need review.
- Written from specs and checklists, not from looking at the rendered frames; the contact sheet should be compared against the texts.
- Arabic and Hebrew mix Latin-free text with digits (90/90, 90) and rely on the platform bidi algorithm; not tested in a screen reader.
- Texts name the exercise; if the UI already shows the name next to the image, the name prefix may be redundant for screen-reader users.
