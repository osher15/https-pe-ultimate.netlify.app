# Timing text proposal — fixed-duration wording

**Status: PROPOSAL ONLY — NOT APPROVED. No timing data or product copy is changed by this document.**

Source: `docs/TIMING_DRAFT_REVIEW.md`. The review currently marks 41 fixed-duration steps across 28 variants with ⚠. The safe principle is: when the fitter may move a step inside a range, prose must not promise a different fixed duration.

## Proposed rule

For a fitted step, replace a fixed minute count in prose with either (a) a parameter rendered from the fitted minutes, or (b) duration-neutral wording. Keep fixed protocol numbers only when they define the protocol itself rather than the block allocation.

## Protocol exceptions needing teacher approval

### Tabata
Keep **8 × 20 s work / 10 s recovery** as the protocol identity. Do not stretch those work/recovery intervals to fill an arbitrary fitted block. If more time is allocated, use it for explanation, setup, recovery, technique feedback, or an explicitly labelled additional set. Proposed UI wording: “Protocol: 8 rounds × 20 s work / 10 s recovery (4:00 work block). Remaining allocated time is setup/recovery.”

### Distance/time pyramid
The current variant says 1–2–3–4–3–2–1 minute running segments with equal walking recovery. Those numbers define the activity and should not silently expand/contract. Proposed UI wording: “Protocol: run 1–2–3–4–3–2–1 min; after each run, walk for the same duration. If the allocated block is shorter, choose a shorter named pyramid rather than changing individual rungs.” The exact shorter pyramid is a teacher decision, not approved here.

## Acceptance before Claude edits product data

Teacher approves the wording rule; protocol-fixed variants are explicitly distinguished from fitted-duration variants; all five languages receive equivalent meaning; the displayed step minutes and prose never contradict each other; no recommendation silently changes a manually edited teacher plan.
